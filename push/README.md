# Подписки на пуш-уведомления

Здесь лежат подписки телефонов, на которые приложение присылает уведомления.
Файл появляется, когда в приложении нажимаете «Включить уведомления» → «Открыть GitHub» → «Commit changes».

- Отправить уведомление по такой подписке может только этот сервис:
  закрытый ключ выводится из секрета репозитория и нигде не хранится.
- Если подписка перестала работать (приложение удалили, уведомления отключили),
  сервис сам удалит файл при следующей отправке.
- Чтобы отключить телефон вручную — удалите его файл.
