# Билеты на горнолыжку

Приложение для телефона (PWA), которое следит за ценами на прямые рейсы из Москвы
на горнолыжные курорты России. Ставится на экран «Домой», без сети показывает
последние сохранённые цены, присылает уведомления.
Всё работает бесплатно на GitHub: свой сервер не нужен.

- **Курорты:** Красная Поляна (Сочи), Эльбрус · Домбай · Архыз (Минеральные Воды), Шерегеш (Новокузнецк),
  Хибины (Апатиты), Манжерок (Горно-Алтайск), Горный воздух (Южно-Сахалинск). По одному аэропорту на курорт.
- **Даты:** вылет не раньше 30.01.2027, возвращение не позже 14.03.2027.
  Сочи и Кавказ — 8 ночей, остальные — 7 или 8.
- **Конференция 08.02–21.02:** поездки, которые задевают эти даты, тоже собираются,
  но показаны серым и в уведомлениях не участвуют.
- **Цена** — туда-обратно на 1 взрослого, только прямые рейсы, с оценкой доплаты за лыжи.

## Как это работает

```
каждые 30 минут (GitHub Actions)
  → цены из кэша Aviasales (Travelpayouts Data API)
  → лучший билет на каждую дату туда и обратно + доплата за багаж
  → все варианты поездок по датам и лучший по каждому курорту
  → история в docs/data  →  приложение на GitHub Pages с графиками
  → уведомления: пуш в приложение и/или Telegram
```

**Уведомления** по каждому курорту:

- 🔔 цена опустилась до порога из `config.yaml`;
- 📉 новый минимум за всё время — дешевле прежнего хотя бы на 1%;
- 📉 цена на 5% ниже минимума за последние сутки;
- ☀️ сводка каждое утро в 8:00 по Москве. Если утром есть повод для уведомления, он входит в сводку.

Ночью (23:00–8:00) уведомления приходят без звука. Об одном и том же дважды не пишет:
о пороге — снова, только если цена поднималась выше него;
о минимуме — только если цена стала ещё ниже.

Каналов два, можно включить любой или оба:

- **Пуш в приложение** — коротко: курорт, цена, даты. Нажатие открывает эту поездку в приложении.
- **Telegram** — подробно: рейсы, время, разбивка цены, ссылка на Aviasales, утром — картинка с графиками.

## Важно про цены

- **Это кэш.** Travelpayouts бесплатно отдаёт билеты, которые другие люди находили в поиске
  Aviasales за последние дни. Живой поиск через API доступен только крупным партнёрам.
  Поэтому у каждой поездки есть ссылка «Проверить на Aviasales» на эти же даты.
  Перед покупкой открывайте её.
- **Багаж — оценка.** API не сообщает, есть ли багаж в тарифе, а в кэше почти всегда лежит
  самый дешёвый тариф без багажа. Поэтому к каждому перелёту прибавляется прикидка
  доплаты за комплект лыж (раздел `baggage` в `config.yaml`): Победа и S7 ≈2 500 ₽, остальные ≈2 000 ₽.
  У Аэрофлота, «России» и «Авроры» лыжи до 15.05.2027 летят бесплатно, но только на тарифах с багажом.
- **Цена складывается из двух билетов в одну сторону.** На внутренних рейсах так обычно не дороже,
  и можно лететь туда и обратно разными авиакомпаниями.
  Если в кэше есть билет туда-обратно одной бронью и он дешевле, берётся он.

## Настройка

Всё, что можно менять, — в [`config.yaml`](config.yaml): пороги, даты конференции, курорты, аэропорты, ночи и доплата за багаж.
Править можно прямо на GitHub с телефона: открыть файл, нажать карандаш, сохранить.
После сохранения проверка запускается сама.

Пример — порог 16 000 ₽ для Сочи:

```yaml
  - id: polyana
    name: Красная Поляна
    airports: [AER]
    nights: [8]
    threshold: 16000
```

## Первый запуск

1. **Секреты.** Settings → Secrets and variables → Actions → New repository secret:
   - `TRAVELPAYOUTS_TOKEN` — обязательно. Токен API: [travelpayouts.com](https://www.travelpayouts.com/) → профиль → API-токен (регистрация бесплатная);
   - `TELEGRAM_BOT_TOKEN` — если нужен Telegram. Токен бота от [@BotFather](https://t.me/BotFather) (`/newbot`),
     потом откройте бота и нажмите «Запустить»;
   - `PUSH_SECRET` — по желанию, любая длинная случайная строка. Из неё получается ключ пуш-уведомлений.
     Без него ключ получается из `TRAVELPAYOUTS_TOKEN`, и при смене токена телефоны придётся подключить заново.
2. **Приложение.** Settings → Pages → Build and deployment: Deploy from a branch → `main` / `/docs` → Save.
   Адрес будет `https://<логин>.github.io/<репозиторий>/`.
3. **Первая проверка.** Actions → «Проверка цен» → Run workflow.
4. **Установка на телефон.**
   - Android (Chrome): откройте адрес → «Установить» в приложении или в меню браузера.
   - iPhone (Safari): откройте адрес → «Поделиться» → «На экран „Домой“». Уведомления на iPhone работают
     только в установленном приложении, iOS 16.4 и новее.
5. **Уведомления в приложении.** Нажмите «Включить уведомления» → «Открыть GitHub» → «Commit changes».
   Подписка телефона сохранится в папку [`push/`](push/), и через пару минут придёт пробное уведомление.

## Для разработки

```bash
pip install -r requirements.txt pytest
python -m pytest -q
python -m tracker --dry-run                 # настоящая проверка, уведомления печатаются вместо отправки
python -m tracker --fixtures DIR --dry-run  # на сохранённых ответах API
```
